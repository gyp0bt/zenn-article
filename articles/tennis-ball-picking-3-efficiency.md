## はじめに — カゴの数と打ち飛ばし比率

[前回の記事](https://zenn.dev/gyp0bt/articles/tennis-ball-picking-2-energy)では、ボール拾いの3つのエネルギーコスト（歩行・屈伸・運搬）を定式化した。200球のスケールでは「屈伸が支配的（83〜91%）」「Style Bは速いがしんどい」「ホッパー最強」という定性的な知見を得た。

しかし、前回の分析では触れられていない**2つの重要な変数**がある。

**1つ目はカゴの数と配置だ。** 1カゴ（ネット脇固定）と4カゴ（最適配置）では、ボールからカゴまでの移動距離が根本的に変わる。実際のスクールでは4カゴを使うが、その配置がどれだけ効率に影響するのかは定量的に示されていない。

**2つ目は打ち飛ばし比率 $\alpha$ だ。** 全部を直接Style Bで拾うか（$\alpha = 0$）、全部を打ち飛ばしてから拾うか（$\alpha = 1$）、あるいは混合するか。この連続パラメータの最適化が、「打ち飛ばし勢はサボっているのか？」という問いの核心に答える。

本記事では、Greedy法（最近傍法）と2-opt局所探索で経路最適化を行い、**4カゴ体制 + クロスDTL分布**での定量シミュレーション結果を示す。

:::message
本記事は連載第3回です。[第1回（問題設定とモデル化）](https://zenn.dev/gyp0bt/articles/tennis-ball-picking-1-modeling)、[第2回（エネルギーモデル）](https://zenn.dev/gyp0bt/articles/tennis-ball-picking-2-energy)を先にお読みください。

## 経路最適化 — CVRPの変種として

### 問題の定式化

ボール位置集合 $\{b_i\}_{i=1}^{N}$ と$K$個のカゴ位置 $\{p_k\}_{k=1}^{K}$ が与えられたとき、各ボールを最近傍のカゴに割り当て、カゴごとに訪問順序を最適化する。

**時間最小化:**

$$\min_{\sigma} T_{total} = \sum_{k=1}^{K} \sum_{trips} \left[ T_{collect}^{(k)}(trip) + T_{return}^{(k)}(trip) + T_{pick}^{(k)}(trip) \right]$$

**エネルギー最小化:**

$$\min_{\sigma} E_{total} = \sum_{k=1}^{K} \left[ E_{walk}^{(k)} + E_{bend}^{(k)} + E_{carry}^{(k)} \right]$$

これは**容量制約付き巡回配送問題（CVRP）**の一種であり、さらに**複数デポ**（複数のカゴ）を持つ拡張版だ。

### 4カゴの場合の解法

4カゴ体制では、まず200球を各カゴに割り当て、次にカゴごとに経路を最適化する。

```python
def optimize_multi_basket(ball_positions, basket_positions, style, basket_config):
    # 1. 各ボールを最近傍カゴに割り当て
    assignments = assign_balls_to_baskets(ball_positions, basket_positions)

    # 2. カゴごとに経路最適化
    for k in range(n_baskets):
        k_balls = ball_positions[assignments == k]
        result = optimize_route(k_balls, basket_positions[k], style)

    # 3. ボトルネック（最も遅いカゴ担当）の時間が全体時間
    total_time = max(basket_results[k].time for k in range(n_baskets))
```

### Greedy法と2-opt改善

Greedy法（最近傍法）でカゴから出発し、常に最も近い未回収ボールを拾いに行く。容量に達したらカゴに戻る。2-optでトリップ内の経路を局所改善する。

## シミュレーション結果 — 4カゴ体制の威力

### 実験設定

| パラメータ | 値 |
|-----------|-----|
| コート | ITF公式ダブルスコート（669 m²） |
| ボール数 | 200球 |
| 分布 | クロス・ダウンザライン（6ゾーンGMM） |
| カゴ | 4カゴ × 50球（k-medians最適配置） |
| カート | ネット脇 $(6.0, 0.0)$ に固定 |
| 体重 | 60 kg |

### カゴ配置の最適化結果

k-medians最適化により、4つのカゴはボールが密集する場所に引き寄せられた。

| カゴ | 位置 | 割り当て球数 |
|------|------|------------|
| カゴ1 | $(-4.2, 10.6)$ 左クロスコーナー付近 | 62球 |
| カゴ2 | $(0.1, -1.7)$ ネットミス帯 | 42球 |
| カゴ3 | $(-0.1, 13.4)$ バックフェンス帯 | 32球 |
| カゴ4 | $(3.6, 10.4)$ 右クロスコーナー付近 | 64球 |

クロスコーナーに2カゴ、ネットミス帯に1カゴ、バックフェンス帯に1カゴが配置された。ボール密度の高い場所にカゴが集まるのは、k-medians最適化の自然な帰結だ。

### 3スタイルの比較結果（4カゴ・200球）

| スタイル | 時間 [秒] | エネルギー [kJ] | トリップ数 | 支配的コスト |
|---------|----------|----------------|-----------|-------------|
| **Style B** しゃがみ移動 | **106** | 216 | 6 | 屈伸 (91%) |
| **Style D** ホッパー | 146 | **22** | 4 | 歩行 (100%) |
| **Style A** ラケット載せ | 253 | 236 | 35 | 屈伸 (83%) |

### 知見 1: Style Bが時間最速

**Style B（しゃがみ移動カゴ持ち）が最速だ。** 106秒でホッパー（146秒）を上回り、Style A（253秒）の半分以下。

この結果は、以下の3つの要因の複合効果による。

1. **拾い時間の圧倒的な短さ**: 0.4秒/球（Style Aの1/5、Style Dの1/3.75）
2. **カゴ往復の不要**: 50球連続で拾い続けられる（Style Aは6球ごとに往復）
3. **4カゴ最適配置**: カゴがボール密集地点にあるため、しゃがみ移動でも短距離で到達

### 知見 2: ホッパーはエネルギー最強だが、時間では劣る

Style D（ホッパー）のエネルギー効率は圧倒的だ（22 kJ — Style Bの1/10）。しかし、**時間では Style B に40秒負ける**。1球あたりの回収時間（1.5秒）がStyle B（0.4秒）の3.75倍かかるためだ。

### 知見 3: Style Aは全メトリクスで最下位

Style A（ラケット載せ）は時間253秒、エネルギー236kJで、両メトリクスともに最も非効率。6球の小容量と2.0秒/球の拾い時間がすべてに影響している。

## カゴの数はどれだけ効率に影響するか

### 1カゴ vs 4カゴの定量比較

Style B で同じ200球を拾った場合、カゴ数による時間・エネルギーの変化を比較する。

| カゴ数 | 時間 [秒] | エネルギー [kJ] | 1カゴ比 |
|-------|----------|----------------|--------|
| 1 | 405 | 309 | 1.00× |
| 2 | 288 | 264 | 0.71× |
| 4 | 106 | 216 | 0.26× |
| 8 | 54 | 201 | 0.13× |

**4カゴにするだけで、1カゴ比で時間は74%削減、エネルギーは30%削減される。** 8カゴならさらに半減するが、現実的なカゴ数の上限を考えると4カゴは非常に良い妥協点だ。

$$\frac{T_{4basket}}{T_{1basket}} = \frac{106}{405} = 0.26$$

この劇的な改善は、カゴを移動可能な「拠点」としてボール密集地に配置できるという構造的な利点に起因する。1カゴ（ネット脇固定）では毎回長距離を往復しなければならないが、4カゴならほとんどのボールの近くにカゴがある。

### カゴ配置: 最適化 vs 固定

k-medians最適化配置と、経験則に基づく固定配置（4隅）を比較する。

| 配置方法 | 時間 [秒] | エネルギー [kJ] |
|---------|----------|----------------|
| k-medians最適化 | 106 | 216 |
| 4隅固定 | 133 | 224 |

最適配置は固定配置より**20%速い**。ボール分布に応じてカゴを配置することの価値が定量的に示された。ただし、固定配置でも1カゴの405秒に比べれば大幅に改善されている（133秒 = 67%削減）。

:::message
実運用上は、「ボールが多く散らばっているコーナーにカゴを置く」という素朴な直観で十分に効果がある。k-medians最適解との差は20%程度であり、最適化の価値は「カゴを4つ使うこと」自体に比べれば小さい。
:::

## 打ち飛ばし比率 $\alpha$ の最適化 — この連載の核心

### 問いの再定式化

全 $N$ 球のうち比率 $\alpha$ を打ち飛ばし（Style C Phase 1）、残り $(1-\alpha)$ をStyle Bで直接拾う**混合戦略**を考える。

$$T_{mixed}(\alpha) = T_{C,phase1}(\alpha N) + T_{C,phase2}(\alpha N) + T_{B}((1-\alpha) N)$$

打ち飛ばすボールは、カゴから遠い順に選択する（遠方のボールほど打ち飛ばしの効果が大きいため）。

### Phase 2の回収スタイルが鍵

打ち飛ばした後、集約点付近に散らばったボールを**どのスタイルで回収するか**で、最適αは劇的に変わる。

#### Case 1: Phase 2 を Style B で回収

| $\alpha$ | 時間 [秒] | 1カゴ・200球 |
|----------|----------|-------------|
| 0.0 | **431** | 全部Style Bで直接拾い |
| 0.1 | 564 |  |
| 0.2 | 621 |  |
| 0.3 | 657 |  |
| 0.5 | 777 |  |
| 0.7 | 881 |  |
| 1.0 | 980 | 全部打ち飛ばし→Style B回収 |

**最適 $\alpha^* = 0$。打ち飛ばしは一切不要。** Style Bで直接拾うのが最速。

これは一見驚くべき結果だが、理由は明確だ。

1. **Style Bの拾い時間（0.4秒/球）は、打ち飛ばし時間（2.5秒/球）の1/6。** 打ち飛ばしの方が1球あたり遅い。
2. 打ち飛ばし後の着地点にはばらつき（$\sigma_{hit} = 3$ m）があるため、**集約後の再回収距離が意外と長い。**
3. Style Bがカゴを持って移動するため、カゴまでの往復が不要。打ち飛ばして「1箇所に集める」メリットが薄い。

#### Case 2: Phase 2 を Style A で回収

| $\alpha$ | 時間 [秒] | 1カゴ・200球 |
|----------|----------|-------------|
| 0.0 | 1,934 | 全部Style Aで直接拾い |
| 0.3 | 1,764 |  |
| 0.5 | 1,687 |  |
| 0.7 | 1,653 |  |
| 0.8 | 1,650 |  |
| **0.9** | **1,646** | 最適 |
| 1.0 | 1,688 |  |

**最適 $\alpha^* = 0.9$。ほぼ全部打ち飛ばすのが最適。**

Style A（2.0秒/球、容量6球）では直接拾いが非常に遅いため、遠方のボールを打ち飛ばして集約する方が効率的。9割を打ち飛ばし、カゴ周辺の1割だけ直接拾うのが最適解となる。

### 打ち飛ばし比率の構造的理解

この結果から、以下の構造的な知見が見える。

:::message alert
**最適打ち飛ばし比率 $\alpha^*$ は、回収スタイルの効率に決定的に依存する。**

- 回収が速い場合（Style B: 0.4秒/球）→ $\alpha^* = 0$（打ち飛ばし不要）
- 回収が遅い場合（Style A: 2.0秒/球）→ $\alpha^* \approx 0.9$（ほぼ全部打ち飛ばし）

打ち飛ばしの価値は「直接拾いの非効率さ」を補填するところにある。拾いが十分に速ければ、打ち飛ばしのオーバーヘッド（2.5秒/球）が見合わない。
:::

つまり、冒頭の問い「打ち飛ばし勢はサボっているのか？」への回答は:

**「カゴを持たずにラケットで拾っている人の隣で打ち飛ばすのは合理的。カゴを持ってしゃがみ拾いしている人の隣で打ち飛ばすのはサボり。」**

### 4カゴ体制での打ち飛ばし比率

4カゴ最適配置の場合、各カゴの担当球に対する最適α:

| カゴ | 担当球数 | 最適α | 備考 |
|------|---------|-------|------|
| カゴ1（左コーナー） | 62球 | 0.0 | Style Bで直接拾い |
| カゴ2（ネットミス帯） | 42球 | 0.0 | Style Bで直接拾い |
| カゴ3（バックフェンス） | 32球 | 0.0 | Style Bで直接拾い |
| カゴ4（右コーナー） | 64球 | 0.0 | Style Bで直接拾い |

**4カゴ体制ではすべてのカゴで $\alpha^* = 0$。** カゴがボール密集地点に配置されているため、「遠くに散らばったボール」自体が存在しない。これが4カゴの真の価値だ——打ち飛ばしの必要性を消滅させる。

## パレートフロント — 速さと楽さのトレードオフ

### パレートフロントの構築

「最も速い拾い方」と「最も楽な拾い方」は同じか？ 移動速度を0.5倍〜1.5倍に変化させ、時間とエネルギーのトレードオフを探索する。

### パレートフロントの構造

4カゴ・200球でのパレートフロントには、旧モデルとは異なる構造が見える。

| スタイル | 時間帯 [秒] | エネルギー帯 [kJ] | 特徴 |
|---------|-----------|-----------------|------|
| Style B | 80〜180 | 200〜240 | **時間最速**、エネルギー中 |
| Style D | 100〜250 | 15〜35 | 時間中、**エネルギー最小** |
| Style A | 180〜400 | 220〜260 | 両メトリクスとも劣る |

### パレート支配の構造

旧モデル（1カゴ・100球・旧Style B）ではStyle Dがすべてを支配していた。しかし、**4カゴ・新Style B**では構造が変わる。

1. **Style B は時間軸で Style D を支配する**（同じエネルギー帯なら常にStyle Bの方が速い、とは限らないが、**時間の最小値ではStyle Bが勝つ**）
2. **Style D はエネルギー軸で Style B を完全に支配する**（エネルギーが1/10）
3. **Style A はパレート非劣解にならない**（Style Bに時間でもエネルギーでも劣る）

つまり、**パレートフロントには Style B と Style D の2つだけが残る**。「速さ重視ならStyle B、楽さ重視ならStyle D」という明確な棲み分けだ。

### パレート最適の意味

Style B で106秒かかるが、もし速度を1.3倍にできれば90秒程度まで短縮できる。ただしエネルギーは230 kJ超に増加する。

$$\frac{\Delta E}{\Delta T} \approx -\frac{14{,}000}{16} \approx -875 \text{ J/秒}$$

1秒短縮するごとに約875 Jの追加エネルギーが必要になる。これは屈伸1回分に匹敵するコストだ。

## 感度分析 — 結果はどれだけ安定か

### ボール数に対する感度

4カゴ体制・Style B で、ボール数を変化させた場合。

| ボール数 | 時間 [秒] | エネルギー [kJ] |
|---------|----------|----------------|
| 50 | 28 | 54 |
| 100 | 55 | 108 |
| 200 | 106 | 216 |
| 300 | 160 | 332 |

時間・エネルギーともにボール数にほぼ**線形に比例**する。ただし、エネルギーの方がわずかに超線形の傾向を持つ。これは累積疲労の影響であり、大量のボールを拾うほど屈伸の非線形コストが効いてくる。

### カゴの数は「4」が最適か

| カゴ数 | 時間 [秒] | 1カゴからの改善率 |
|-------|----------|----------------|
| 1 | 405 | — |
| 2 | 288 | 29% |
| **4** | **106** | **74%** |
| 8 | 54 | 87% |

1→4カゴの改善（74%）は劇的だが、4→8カゴの追加改善（13ポイント）は限定的。4カゴはコスト効率の良いスイートスポットだ。

## 体感の速度序列は正しかったのか

冒頭で示した体感の速度序列を、シミュレーション結果と照合する。

**体感**: C+B混合 > B単独 > A

**シミュレーション（4カゴ・200球）**: B(106秒) > D(146秒) > A(253秒)

4カゴ体制では打ち飛ばし混合（C+B）の$\alpha^*=0$、つまり**B単独が最適**となるため:

**シミュレーション結論**: B単独 ≧ C+B混合 > A

体感の「C+B混合が最速」は、**1カゴ体制かつ回収がStyle A的な場合には正しいが、4カゴ体制ではStyle B単独が最適**という条件付きの結論になる。

つまり**私がしゃがんでカゴを持ちながら黙々と拾っているのは、4カゴ体制下では最速戦略だった。** ……しんどいのは変わらないが、最適であるという数理的なお墨付きを得られたことは、ささやかな救いだ。

## まとめ — 4カゴと打ち飛ばし比率が描く最適戦略の全体像

### 主要な結果

1. **Style B（しゃがみ移動カゴ持ち）が4カゴ体制で最速**: 106秒（Style Aの2.4倍速、Style Dより40秒速い）
2. **4カゴは1カゴ比で74%の時間削減**: 405秒 → 106秒。カゴの配置が効率を劇的に左右する
3. **カゴ配置最適化の価値**: 最適配置 vs 固定配置で20%の改善。ただし「4カゴ使うこと」自体の価値（74%改善）の方が圧倒的に大きい
4. **打ち飛ばし比率 $\alpha^*$ は回収スタイル依存**:
   - Style B回収 → $\alpha^* = 0$（打ち飛ばし不要）
   - Style A回収 → $\alpha^* \approx 0.9$（ほぼ全部打ち飛ばし）
5. **パレートフロントにはStyle BとDだけが残る**: 速さのB、楽さのD
6. **Style Aは全メトリクスで最下位**: パレート非劣解にならない

### 「打ち飛ばし勢はサボりか？」への最終回答

4カゴ体制で全員がStyle B（しゃがみ拾い）で拾える場合、打ち飛ばしは**数理的にサボりである**。Style Bの拾い時間（0.4秒/球）が打ち飛ばし時間（2.5秒/球）を大幅に下回るため、打ち飛ばしは時間の浪費にしかならない。

ただし、Style A（ラケット載せ）しかできない状況では、打ち飛ばしは**合理的な戦略**である。遠方のボールを打ち飛ばして集約し、カゴ近くで回収する方が、ラケットに6球ずつ載せて往復するより効率的だ。

**最適解は、道具の選択（カゴを持つか否か）にある。アルゴリズムの改善より、問題設定の変更の方がインパクトが大きい。**

## 次回予告 — 協調の数理

ここまでは1人で全球を拾う「個人最適化」を考えてきた。しかし現実のテニススクールでは6〜12人が同時にボール拾いをする。

次回の記事では、$M$ 人によるコートの**領域分割**と**協調戦略**を数理最適化する。

$$\min_{\{A_j\}} \max_{j=1}^{M} T_j(A_j)$$

全員の完了時間のボトルネック（最も遅い人）を最小化する——ボロノイ分割、均等分割、密度ベース分割の3つの戦略を比較する。
