## はじめに — 理論を数値で検証する

[前回](https://zenn.dev/gyp0bt/articles/tennis-ball-picking-2-energy)はボール拾いにおけるエネルギーモデルを構築した。歩行・屈伸・運搬の3コスト要素を定式化し、4スタイルのエネルギープロファイルを比較した。

しかし、エネルギーモデルだけでは**最適な戦略**は決まらない。エネルギーが少なくても時間がかかりすぎるなら実用的でないし、逆に速くても身体を壊すほど疲れるなら持続可能でない。

本記事では、個人の経路最適化問題を実際にシミュレーションで解き、**時間効率とエネルギー効率の全貌**を明らかにする。

$$\min_{\sigma} \left( T_{total}(\sigma),\ E_{total}(\sigma) \right)$$

ここで $\sigma$ はボールの訪問順序。この2目的最適化問題のパレートフロントを導出し、各スタイルの「本当の実力」を定量的に評価する。

:::message
本記事は連載第3回です。[第1回（問題設定とモデル化）](https://zenn.dev/gyp0bt/articles/tennis-ball-picking-1-modeling)、[第2回（エネルギーモデル）](https://zenn.dev/gyp0bt/articles/tennis-ball-picking-2-energy)を先にお読みください。

## 経路最適化問題の設定

### 容量制約付きTSPとしての定式化

ボール拾いの経路最適化は、**容量制約付き巡回セールスマン問題（CVRP）** に帰着する。

各スタイルには最大積載数 $C$ がある。$N$ 個のボールを回収するには、1トリップあたり最大 $C$ 個を拾い、カゴに戻って下ろすという**往復**を繰り返す。この往復回数は最低 $\lceil N/C \rceil$ 回必要だ。

| スタイル | 容量 $C$ | 100球の最低トリップ数 |
|---------|---------|-------------------|
| A: ラケット載せ | 5球 | 20往復 |
| B: 手拾い直行 | 3球 | 34往復 |
| C: 打ち飛ばし | 100球 | 1往復 |
| D: ホッパー巡回 | 72球 | 2往復 |

この表だけで直観的に分かることがある。Style BはStyle Aの2倍近いトリップ数が必要で、カゴとの往復距離だけでも大きなハンデを背負っている。一方、Style CとDは実質1〜2トリップで済むため、往復のオーバーヘッドがほぼゼロだ。

### 目的関数

各トリップ $j$ について、時間とエネルギーを計算する。

**時間**:

$$T_{trip}^{(j)} = t_{pick}(n_j) + t_{collect}^{(j)} + t_{return}^{(j)}$$

- $t_{pick}$: 拾い上げ時間（$n_j \times t_{pick/ball}$）
- $t_{collect}$: ボール間の移動時間
- $t_{return}$: カゴへの帰還時間（荷重による速度低下を反映）

**エネルギー**:

$$E_{trip}^{(j)} = E_{walk}^{(j)} + E_{bend}^{(j)} + E_{carry}^{(j)}$$

全体の目的関数は全トリップの総和:

$$T_{total} = \sum_j T_{trip}^{(j)}, \quad E_{total} = \sum_j E_{trip}^{(j)}$$

## 解法: Greedy + 2-opt

### なぜ厳密解を求めないか

CVRPはNP困難であり、100個のボールに対する厳密解の計算は現実的でない。そこで、2段階のヒューリスティクスを採用する。

### Step 1: Greedy Nearest Neighbor

カゴ位置からスタートし、常に**最も近い未回収ボール**を拾いに行く。容量に達したらカゴに戻り、次のトリップを開始する。

```python
def greedy_route(ball_positions, basket_position, capacity):
    remaining = set(range(len(ball_positions)))
    trips = []
    while remaining:
        trip, current_pos = [], basket_position
        while remaining and len(trip) < capacity:
            nearest = min(remaining,
                key=lambda i: np.linalg.norm(
                    ball_positions[i] - current_pos))
            trip.append(nearest)
            current_pos = ball_positions[nearest]
            remaining.remove(nearest)
        trips.append(trip)
    return trips
```

Greedy法は実装が単純で高速だが、**交差する経路**を生みやすいという弱点がある。例えば、右端のボールを拾った後に左端のボールを拾い、また右端に戻るような無駄な往復が発生しうる。

### Step 2: 2-opt 局所探索

2-opt交換は、経路中の2辺を選んでそれらの間を反転させることで、交差を解消する古典的な手法だ。

各トリップの経路（カゴ → ボール群 → カゴ）に対して2-optを適用し、**移動距離を局所的に最小化**する。

```python
def two_opt_improve(trip_indices, ball_positions, basket_position):
    route = list(trip_indices)
    improved = True
    while improved:
        improved = False
        for i in range(len(route) - 1):
            for j in range(i + 1, len(route)):
                new_route = route[:i] + route[i:j+1][::-1] + route[j+1:]
                if route_distance(new_route) < route_distance(route):
                    route = new_route
                    improved = True
                    break
            if improved:
                break
    return route
```

### 改善効果

2-optの適用による改善率はスタイルによって異なる。

| スタイル | Greedy | 2-opt | 改善率 |
|---------|--------|-------|-------|
| A: ラケット載せ | 823秒 | 806秒 | 2.1% |
| B: 手拾い直行 | 922秒 | 920秒 | 0.3% |
| C: 打ち飛ばし | 384秒 | 352秒 | 8.3% |
| D: ホッパー巡回 | 338秒 | 310秒 | 8.2% |

興味深いパターンが見える。**容量の大きいスタイル（C, D）ほど2-optの改善が効きやすい**。理由は明確だ。1トリップで訪問するボール数が多いほど、経路の交差が発生しやすく、2-optが解消できる余地が大きい。逆にStyle B（容量3）では1トリップで3球しか拾わないため、最適化の余地がほとんどない。

## シミュレーション結果

### 基本条件

- **ボール数**: 100球
- **分布**: ストローク練習（北側ベースライン帯60%、ネット帯15%、サイド帯15%、バックフェンス帯10%）
- **カゴ位置**: ネット脇 $(6.0, 0.0)$
- **体重**: 60 kg

### スタイル別の総合性能

| スタイル | 時間 [秒] | 往復 | $E_{walk}$ [kJ] | $E_{bend}$ [kJ] | $E_{carry}$ [kJ] | $E_{total}$ [kJ] |
|---------|----------|------|-----------------|-----------------|------------------|------------------|
| A: ラケット載せ | 806 | 20 | 89.0 | 111.0 | 1.0 | 201 |
| B: 手拾い直行 | 920 | 34 | 160.5 | 111.0 | 1.0 | 272 |
| C: 打ち飛ばし | 352 | 1 | 24.3 | 0 | 0.1 | 24 |
| D: ホッパー巡回 | 310 | 2 | 25.0 | 0 | 0.8 | 26 |

### 4つの発見

#### 1. 屈伸コストの支配性は健在

前回の記事で指摘した「屈伸が支配的コスト」は、経路最適化を適用しても変わらない。Style A, Bでは屈伸エネルギーが全体の55〜41%を占める。**いくら経路を最適化しても、屈伸を100回行う事実は変わらない**。

#### 2. Style BはStyle Aの「下位互換」

Style BはStyle Aより**時間もエネルギーも悪い**。原因は明確だ。容量がStyle A（5球）の約半分（3球）しかなく、往復回数が1.7倍になる。歩行エネルギーが80%も多い一方、屈伸エネルギーは同じ（どちらも100回かがむ）。時間の差（114秒 = 約2分）は、34回の帰還コストの蓄積だ。

#### 3. Style CとDは別世界

Style C（打ち飛ばし）とD（ホッパー）のエネルギー消費は、Style A, Bの**約10分の1**だ。屈伸が不要なことに加え、少ない往復回数で歩行距離自体が短い。「楽に速い」という理想的な性能を発揮する。

#### 4. 時間ではDが最速、エネルギーではCが最小

Style Dは310秒で最速だが、エネルギーではStyle C（24 kJ）がわずかに上回る。この差はホッパーの重量に起因する運搬エネルギーの違い（0.8 kJ vs 0.1 kJ）に由来する。わずかな差だが、この2スタイルがパレートフロント上で異なる位置を占めることになる。

## パレートフロント — 時間 vs エネルギーの最適解

### パレート最適解とは

2つの目的関数（時間 $T$ とエネルギー $E$）を同時に最小化したいとき、**一方を改善すると他方が悪化する**というトレードオフ関係にある解の集合をパレートフロントと呼ぶ。

$$\text{解 } x \text{ がパレート最適} \iff \nexists y : T(y) \leq T(x) \wedge E(y) \leq E(x) \text{ (少なくとも一方は厳密)}$$

### 今回のパレートフロント

100球のストローク分布に対するシミュレーション結果を $(T, E)$ 空間にプロットすると:

| スタイル | $T$ [秒] | $E$ [kJ] | パレート最適？ |
|---------|----------|----------|-------------|
| A: ラケット載せ | 806 | 201 | No（C, Dに支配される） |
| B: 手拾い直行 | 920 | 272 | No（全員に支配される） |
| C: 打ち飛ばし | 352 | 24 | **Yes**（エネルギー最小） |
| D: ホッパー巡回 | 310 | 26 | **Yes**（時間最小） |

**Style A, Bはパレート支配される**。つまり、Style C, Dのどちらかを選べば、Style A, Bより時間もエネルギーも改善できる。

パレートフロント上にあるのはStyle CとDの2点のみ。これは:

- **時間重視なら**: Style D（ホッパー巡回）
- **エネルギー重視なら**: Style C（打ち飛ばし集約）

という明快な結論を与える。

:::message alert
「道具の力」は圧倒的だ。ホッパーという専用道具を使うことで、手拾いの約3分の1の時間と10分の1のエネルギーで同じ仕事ができる。道具の設計（屈伸不要、大容量）が人体の非効率性を根本から回避している。
:::

## 感度分析 — 結論は頑健か

### ボール数への依存性

ストローク練習分布で、ボール数を50, 100, 150球と変化させたときの平均性能（5試行平均）:

| ボール数 | 指標 | Style A | Style B | Style C | Style D |
|---------|------|---------|---------|---------|---------|
| 50球 | 時間 [秒] | 421 | 475 | 193 | 164 |
| | エネルギー [kJ] | 97 | 132 | 16 | 14 |
| 100球 | 時間 [秒] | 813 | 930 | 342 | 306 |
| | エネルギー [kJ] | 202 | 275 | 22 | 25 |
| 150球 | 時間 [秒] | 1193 | 1339 | 508 | 437 |
| | エネルギー [kJ] | 319 | 421 | 32 | 34 |

スケーリングの特徴:

1. **Style A, B**: ボール数にほぼ比例して時間・エネルギーが増加する。線形スケーリング。
2. **Style C, D**: 時間はほぼ線形に増えるが、エネルギーの増加は緩やかだ。屈伸がないためエネルギーの主成分は歩行距離のみで、ボール間距離はボール数の平方根程度にしかスケールしない。
3. **全ボール数において、パレートフロントはStyle C, Dが独占**。Style A, Bが逆転するシナリオは見つからなかった。

### 分布パターンへの依存性

ストローク練習（広範囲分散）とボレー練習（ネット付近集中）で100球の比較:

| 分布 | 指標 | Style A | Style B | Style C | Style D |
|------|------|---------|---------|---------|---------|
| ストローク | 時間 [秒] | 813 | 930 | 342 | 306 |
| | エネルギー [kJ] | 202 | 275 | 22 | 25 |
| ボレー | 時間 [秒] | 570 | 622 | 323 | 258 |
| | エネルギー [kJ] | 166 | 206 | 17 | 17 |

**ボレー分布では全スタイルが速くなる**（ボールが密集しているため移動距離が短い）。しかし、改善幅はスタイルによって大きく異なる:

- Style A: 30%の時間短縮（806→570秒）
- Style D: 17%の時間短縮（306→258秒）

ボールが密集するとStyle A, Bの往復オーバーヘッドが相対的に軽減されるため、改善幅が大きい。一方、Style C, Dは元から効率が良いため、改善幅は限定的だ。

**それでもパレートフロントの構造は変わらない** — Style C, Dが支配的であるという結論は分布パターンに対して頑健だ。

## 考察 — なぜ手拾いを選ぶのか

シミュレーション結果は「ホッパーか打ち飛ばしが最適」と告げている。しかし現実のテニススクールでは、手拾い（Style B）が最も一般的だ。

なぜか？

この乖離にはモデル化されていない要因がある:

1. **道具の制約**: ホッパーは高価であり、スクールに十分な数がないことが多い
2. **技術の制約**: ラケットでボールを正確に打ち飛ばすにはそれなりの技術が必要
3. **社会的規範**: 「手で拾うのが普通」という暗黙の了解がある
4. **短期的な合理性**: 1回の屈伸コスト（$\approx 820$ J）は体感として小さく、100回の累積で初めて問題になる。人間は累積コストを過小評価する傾向がある

特に4番目は行動経済学的に興味深い。**1回あたりの非効率は小さくても、繰り返しの中で指数的に蓄積する** — これはまさに累積疲労モデル $E_{bend}^{(n)} = E_{base} \cdot (1 + \beta \cdot n)$ が捉えている現象だ。

## まとめと次回予告

本記事では、4つのボール拾いスタイルの収集効率をシミュレーションで定量評価し、以下の知見を得た。

1. **経路最適化（Greedy + 2-opt）** を適用しても、スタイル間の性能差は大きく変わらない。スタイルの選択が経路の最適化よりはるかに重要
2. **パレートフロントはStyle C（打ち飛ばし）とD（ホッパー）が独占**。Style A, Bは両目的で支配される
3. **この結論はボール数・分布パターンに対して頑健**。50〜150球、ストローク・ボレー分布のいずれでも構造は変わらない
4. **道具の力は圧倒的** — 屈伸回避と大容量が性能を桁違いに改善する

しかし、ここまでは**個人**の最適化だった。実際のテニススクールでは6〜12人が同時にボールを拾う。個人最適の延長では**領域の衝突**や**非効率な重複**が生じる。

次回は、複数人でのボール拾いに焦点を当て、**最適フォーメーション**（領域分割・スタイル混合）を数理的に導出する。

$$\min_{\{A_j\}} \max_{j=1}^{M} T_j(A_j)$$

全員の完了時間の最大値（ボトルネック）を最小化するこの問題は、ボロノイ分割や密度ベース分割といった幾何学的手法と深く関わっている。
